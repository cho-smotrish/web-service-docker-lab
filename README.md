Для запуска нужно зайти в корневую папку проекта, где находится файл docker-compose.yml.
Для певрого запуска использовать команду:
docker compose up --build -d

Если нужно параллельно смотреть логи, можно убрать ключ -d:
docker compose up --build

Для последующих запусков, если не было сделано изменений в коде, можно использовать команду:
docker compose up -d

Для каждого сервиса, кроме БД, созданы файлы Dockerfile. docker compose up --build сначала собирает образ для каждого сервиса, затем его запускает.

После запуска сервис доступен на:
localhost:8080
